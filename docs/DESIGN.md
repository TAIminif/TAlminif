# MoonC3D 0.2.1 设计与语义

## 数据流

`Bytes → Header + Parameters → Layout → Reader → Frame/Document`。

在读取多字节字段前检查处理器编号84/85/86，分别使用 Intel IEEE 小端、DEC VAX F 浮点、MIPS IEEE 大端。参数区通过界限检查和向前记录偏移解析；所有记录读完后验证引用、重复项、维度和载荷长度。每个参数保留来源处理器、锁定状态、说明字节和原始数据字节。类型化访问按来源解码；跨编码写出转换整型/实数载荷，字符/字节不变。VAX E=1/2 直接以 Double 数学展开，避免先经过 IEEE float32 造成低位损失；VAX reserved operand 拒绝读取，写出非有限、下溢或上溢显式报错。

Layout 将头部和 POINT、ANALOG、TRIAL 参数解析为帧布局。POINT:FRAMES 优先于可能描述录像区间的头部范围；长试验支持 POINT:LONG_FRAMES 与 TRIAL 双 uint16 帧号。计数、采样率或数据起点冲突报错。

Reader 持有整个输入文件，不预先解码所有帧；`analyze` 每次处理一帧，仅保留通道统计状态。`read`、编辑和 JSON 导出保留全部帧。Node 主机只负责文件/进程接口，解析、验证、编辑和 CSV 编码均在 MoonBit 中执行。

## 数值与时间

- 正 POINT:SCALE：int16 坐标乘其绝对值；负比例：XYZ 是已缩放的 float32 坐标。
- 第四个点值：整数存储为有符号16位字；浮点存储为该整数的数值表示。负值表示缺失；低8位是残差除以比例绝对值，高7位是相机掩码。
- 缺失点及非有限坐标规范化为0并设置 `valid=false`。分析忽略缺失坐标，CSV 留空；重新编码缺失点为0坐标与-1第四字。
- 模拟物理值为 `(raw - offset) * channel_scale * global_scale`，浮点同样校准。数组为 `[channel][subsample]`；文件按子采样交错通道。
- 帧索引从0开始，帧号从 `first_frame` 开始。绝对时间为 `(frame_number - 1) / point_rate`；模拟时间加 `subsample / analog_rate`。
- `crop(start,end)` 保留半开区间完整帧和子采样，筛选同一时间区间事件。默认帧号重置为1并减去原片段起点；库可设置 `rebase=false`。
- `crop_time(start,end)` 选择帧起始时间处于绝对秒数半开区间内的帧，不插值。它和 `index_at` 在 `time_at` 的同一实际浮点时间轴上二分查找，不使用乘法后的ceil/floor或任意epsilon。相邻可表示时间、非1起点及最大可表示帧号均有回归测试。
- 比例/采样率/事件时间采用目标处理器的32位实数，往返有对应格式内舍入。模拟子采样数使用头部整数；POINT和ANALOG采样率各自的REAL*4舍入区间必须存在合法整数倍关系，含中点的奇偶舍入规则。这允许59.94等小数率的独立量化误差，拒绝超出表示精度的真正冲突。写出将已编码参数与文件头重新解码，用实际目标比例与校准参数编码帧。整数编码采用最近整数量化；残差最多255个比例单位，相机掩码0..127；超范围拒绝写出。

## 编辑与元数据

编辑函数创建新帧/通道数组。API 管理的 POINT、ANALOG、TRIAL、EVENT 字段根据最终数据重建；写出重新计算参数块数和 DATA_START，以512字节对齐。头部事件迁移到 EVENT 参数。保留未解释的头部字节，只清除已迁移的事件字段；记录顺序与块位置可能规范化。

`Parameters.set/remove` 默认遵守参数锁，只有显式 `override_locked=true` 才能覆盖。文件编辑会更新负责的标准字段，包括源文件锁定的标准字段，并保留锁标志。

通道选择同步重排标签、描述、单位、比例和偏移。模拟选择还处理已知 GAIN/RANGE 向量；有效力平台存在时拒绝操作。上述通道字段按255项连续分段，重排后重新分段并删除旧尾段。未知参数同编码保持原字节，跨编码按参数类型转码；自定义通道引用需要应用者自行解释更新。

`MoonC3D/1` JSON 包含物理值和以十六进制表示的原始参数载荷及其 processor。缺省 processor 解释为 Intel，以兼容旧版 JSON。导入验证结构、维度、计数、连续帧号、深度和限额，再重建标准字段；拒绝未知语义字段。原始参数不能覆盖语义数据的最终计数。

`read_parameter_file` / `write_parameter_file` 提供参数独立文件 API，不为元数据虚构三维帧。读取遵循首字节指针，参数区可以从第1块或后续块开始；写出采用第1块。三种处理器均支持。

## 默认限额

| 资源 | 上限 |
| --- | ---: |
| 文件/CLI 输出 | 128 MiB |
| 参数记录 | 4096 |
| 参数载荷预算 | 1 MiB，且参数块数受 uint8 限制 |
| 帧数 | 200000 |
| 点/模拟通道 | 各65535；每帧模拟总样本仍≤65535 |
| 每帧子采样 | 2048 |
| 总数值 | 20000000 |
| 文本预算 | 参数表示与解码语义表示分别各1 MiB，均按UTF-8字节 |
| JSON 嵌套 | 64 |
| 诊断数量 | 最多1000 |

库调用者可传入 `Limits`，构造、JSON导入、编辑重建及最终校验沿用同一组限额，仍受C3D格式本身的维度和数值范围限制。参数文本预算包括组/参数名称、说明和字符载荷；语义文本预算包括点标签/描述/单位、模拟通道标签/描述/单位和事件文本。两种表示分别限制，不把同一字段的两种表示重复相加。JSON输入大小也按UTF-8字节计量。分配载荷/帧前检查界限和乘加溢出。CLI 使用用户指定路径，输出独占创建。

## 模块与验证

`model/binary` 定义模型和底层安全操作；`processor` 处理字节序和 VAX 数值；`parameter_codec/parameter_api/parameter_series/parameter_file` 处理记录、类型访问、分段及独立文件；`header/frame_codec` 解析标准字段、校准样本；`events/file_codec` 处理完整文件；`edit` 编辑试验；`json_exchange/csv_export` 数据交换；`analysis` 提供在线 Welford 均值、样本方差、RMS、缺失段与诊断。

单位测试覆盖核心协议及异常分支。Python 双向对照覆盖 Intel 整数/浮点、非零首帧、多子采样、校准、缺失点、事件和自定义参数。官方 Sample01/02 与三编码×两种存储×有/无符号的511通道案例由 `scripts/compatibility_cases.py` 验证，具体证据和边界见 COMPATIBILITY.md。未知处理器编号返回 `unsupported`。这些测试不能替代所有厂商文件的兼容验证。
