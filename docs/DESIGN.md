# MoonC3D 0.1.0 设计与语义

## 数据流

`Bytes → Header + Parameters → Layout → Reader → Frame/Document`。

在读取浮点字段前检查处理器编号84。参数区通过界限检查和向前记录偏移解析；所有记录读完后验证引用、重复项、维度和载荷长度。每个参数保留锁定状态、说明字节和数据字节。

Layout 将头部和 POINT、ANALOG、TRIAL 参数解析为帧布局。POINT:FRAMES 优先于可能描述录像区间的头部范围；长试验支持 POINT:LONG_FRAMES 与 TRIAL 双 uint16 帧号。计数、采样率或数据起点冲突报错。

Reader 持有整个输入文件，不预先解码所有帧；`analyze` 每次处理一帧，仅保留通道统计状态。`read`、编辑和 JSON 导出保留全部帧。Node 主机只负责文件/进程接口，解析、验证、编辑和 CSV 编码均在 MoonBit 中执行。

## 数值与时间

- 正 POINT:SCALE：int16 坐标乘其绝对值；负比例：XYZ 是已缩放的 float32 坐标。
- 第四个点值：整数存储为有符号16位字；浮点存储为该整数的数值表示。负值表示缺失；低8位是残差除以比例绝对值，高7位是相机掩码。
- 缺失点及非有限坐标规范化为0并设置 `valid=false`。分析忽略缺失坐标，CSV 留空；重新编码缺失点为0坐标与-1第四字。
- 模拟物理值为 `(raw - offset) * channel_scale * global_scale`，浮点同样校准。数组为 `[channel][subsample]`；文件按子采样交错通道。
- 帧索引从0开始，帧号从 `first_frame` 开始。绝对时间为 `(frame_number - 1) / point_rate`；模拟时间加 `subsample / analog_rate`。
- `crop(start,end)` 保留半开区间完整帧和子采样，筛选同一时间区间事件。默认帧号重置为1并减去原片段起点；库可设置 `rebase=false`。
- `crop_time(start,end)` 选择帧起始时间处于绝对秒数区间内的帧，不插值。边界按文件实际浮点值比较。
- 比例/采样率/事件时间采用 float32，往返有该精度内舍入。整数编码采用最近整数量化；残差最多255个比例单位，相机掩码0..127；超范围拒绝写出。

## 编辑与元数据

编辑函数创建新帧/通道数组。API 管理的 POINT、ANALOG、TRIAL、EVENT 字段根据最终数据重建；写出重新计算参数块数和 DATA_START，以512字节对齐。头部事件迁移到 EVENT 参数。不会保留无语义的头部填充或记录顺序。

`Parameters.set/remove` 默认遵守参数锁，只有显式 `override_locked=true` 才能覆盖。文件编辑会更新负责的标准字段，包括源文件锁定的标准字段，并保留锁标志。

通道选择同步重排标签、描述、单位、比例和偏移。模拟选择还处理已知 GAIN/RANGE 向量；有效力平台存在时拒绝操作。未知参数保持原字节，自定义通道引用需要应用者自行解释更新。

`MoonC3D/1` JSON 包含物理值和以十六进制表示的原始参数载荷。导入验证结构、维度、计数、连续帧号、深度和限额，再重建标准字段；拒绝未知语义字段。原始参数不能覆盖语义数据的最终计数。

## 默认限额

| 资源 | 上限 |
| --- | ---: |
| 文件/CLI 输出 | 128 MiB |
| 参数记录 | 4096 |
| 参数载荷预算 | 1 MiB，且参数块数受 uint8 限制 |
| 帧数 | 200000 |
| 点/模拟通道 | 各255 |
| 每帧子采样 | 2048 |
| 总数值 | 20000000 |
| 文本预算 | 1 MiB |
| JSON 嵌套 | 64 |
| 诊断数量 | 最多1000 |

库调用者可传入 `Limits`，仍受 C3D 格式本身的维度和数值范围限制。分配载荷/帧前检查界限和乘加溢出。CLI 使用用户指定路径，输出独占创建。

## 模块与验证

`model/binary` 定义模型和底层安全操作；`parameter_codec/parameter_api` 处理记录及类型访问；`header/frame_codec` 解析标准字段、校准样本；`events/file_codec` 处理完整文件；`edit` 编辑试验；`json_exchange/csv_export` 数据交换；`analysis` 提供在线 Welford 均值、样本方差、RMS、缺失段与诊断。

单位测试覆盖核心协议及异常分支。Python 双向对照覆盖 Intel 整数/浮点、非零首帧、多子采样、校准、缺失点、事件和自定义参数；不能替代所有厂商文件的兼容验证。未支持编码明确返回 `unsupported`。
