# C3D 兼容范围、终点与复现证据

版本：0.2.1；记录更新：2026-10-20。

本地回归测试为82项，覆盖小数采样率、精确时间边界和自定义限额；21个兼容案例与54个目标编码输出继续验证。最新工程摘要见 [VERIFICATION-20261020.json](VERIFICATION-20261020.json)，历史快照见 [VERIFICATION-20261016.json](VERIFICATION-20261016.json)；线上 native 及重新执行结果见仓库 CI。

## 最终交付范围与完成判定

MoonC3D 的交付目标是 [2021 C3D 官方指南](https://www.c3d.org/docs/C3D_User_Guide.pdf) 定义的三维点、同步模拟信号和参数交换内核。最终范围包括 Intel、DEC/VAX、SGI/MIPS 三种处理器编码，整数/浮点两种数据存储，以及超过255项的连续编号通道参数。DEC/VAX、MIPS、LABELS2 不再作为项目终点的排除项。

兼容完成用下列清单判定，而非仅以能够打开文件判定：

| 验收项 | 本次实现与证据 |
| --- | --- |
| 六种表示读写 | 三处理器 × int16/float32；官方 Sample01 六个原件逐帧对照，并验证每个目标编码输出 |
| 完整参数记录 | 字符、字节、16位整数、32位实数；最多7维；组、说明、锁与未知厂商参数；跨编码按数值类型转码 |
| 大通道列表 | POINT 的 LABELS/DESCRIPTIONS；ANALOG 的 LABELS/DESCRIPTIONS/UNITS/SCALE/OFFSET；连续2、3等后缀；511点与511模拟通道案例 |
| 同步数据 | XYZ、残差、相机掩码、缺失点；模拟子采样、SIGNED/UNSIGNED、每通道和总比例/偏移校准；逐样本比较物理值 |
| 布局与长试验 | 遵循参数区/数据区指针；POINT:FRAMES/LONG_FRAMES、TRIAL双字帧号；界限和溢出检查 |
| 事件与独立参数文件 | EVENT 与传统2/4字符头部事件合并；三处理器参数独立文件读写；非首帧事件时间轴测试 |
| 处理后仍可交换 | 跨编码转换、JSON往返、裁剪、跨255边界选择/重排，重建相关参数并清除旧尾段 |
| 工程交付 | 四后端CI、可运行示例、固定版本独立对照、可复现报告及指定GitHub仓库中的公开源码 |

前七项是0.2.0已实现、0.2.1继续回归的目标，测试命令如下。本项目按2026-10-16更新的交付范围仅向GitHub仓库交付，跨项目使用通过本地工作区依赖。后续稳定版的兼容终点沿用此清单；扩大厂商样本回归不能替代现有检查。

“兼容”指标准数据表示、元数据和处理结果可交换；不承诺逐字节相同、所有厂商私有语义自动解释或任意损坏文件均可读取。

## 编码矩阵

| 处理器编号 | 整数与实数表示 | int16数据 | 浮点数据 | 目标编码写出 |
| --- | --- | --- | --- | --- |
| 84 Intel | 整数小端，IEEE binary32小端 | 已验证 | 已验证 | 已验证 |
| 85 DEC/VAX | 整数小端，VAX F_floating | 已验证 | 已验证 | 已验证 |
| 86 SGI/MIPS | 整数大端，IEEE binary32大端 | 已验证 | 已验证 | 已验证 |

头部、记录偏移、参数载荷、TRIAL字对、事件和数据帧均遵循处理器编码。VAX 的低指数值使用 Double 精确展开，再按目标格式舍入；reserved operand、不可表示的非有限数及VAX上/下溢显式报错。采样率关系按源/目标格式的精确舍入区间校验，真正超出表示精度的冲突仍拒绝。

## 可复现案例

```sh
moon build --target js --release
python -m pip install -r requirements-test.txt
python scripts/compatibility_cases.py --download-official
```

脚本输出唯一的 `artifacts/compatibility-*/report.json` 路径；失败退出非0。报告、源样本说明、修正记录、生成文件和JSON均保留供检查。`--skip-official` 只用于离线合成测试，报告明确标记缩减范围，不能冒充完整验证。

### 1. 官方数据跨编码交换

[C3D.org 样本页](https://www.c3d.org/sampledata.html)提供同一试验的六种表示。脚本固定档案哈希，分别对照各文件全部有效XYZ、残差、相机掩码、模拟物理值及事件，再将每个试验写成三种目标编码，使用 `py-c3d 0.6.0` 独立读取。

| 下载源 | SHA-256 |
| --- | --- |
| [Sample01.zip](https://www.c3d.org/data/Sample01.zip) | `15f7277768d52a0a834c7fb96e07bdc916bfc076b6faf76e8b2654a04893308d` |
| [Sample02.zip](https://www.c3d.org/data/Sample02.zip) | `bf83f6197745ea1ced2a55cae9115b08816055d63c6d4463b53085a636f42a9b` |

实测为10个未经修改的有效原件及2个明确修正的本地副本通过，共36个目标编码输出。Sample02 的两个 SGI/MIPS 原件末尾 POINT:LABELS 记录在从0计数的5429字节处写入 `3f 01`，按MIPS解码的跳转超出参数区；原件应返回结构化 `invalid`。脚本保留原件，仅在名为 `-repaired` 的副本中将这两个字节改为 `01 3f`（正确偏移319），分别记录前后哈希并核对原始/修正文件在外部工具中的全部数据相同。**这两份不能称作原件直接通过。**

Sample02 的 DEC 整数文件有8个头部事件，其余五种表示有9个；各文件对照自身的独立结果，不人为制造一致。

### 2. 511点与511模拟通道

生成3帧、每帧511点、511个模拟通道、每通道3个子采样。每个通道具有可区分标签、描述、单位、比例和偏移；数据含有效/缺失点、残差、相机掩码及事件。三种处理器分别测试整数、浮点和无符号整数，共9个案例，另验证18个跨编码输出。

脚本中的独立Python字节解码器和预先定义的物理公式核对每个样本，不能仅靠本库自己读写证明正确。`py-c3d 0.6.0` 的分段模拟校准支持有限，因此不充当大通道案例的对照依据。

验证索引254、255、510等跨段边界的选择与重排，检查 LABELS2/3、SCALE2/3、OFFSET2/3 等对应正确，缩减后旧尾段不残留；裁剪同时检查模拟子采样和事件时间。

### 3. 精度、历史布局和异常文件

MoonBit测试额外覆盖VAX正规指数范围、低指数尾数、舍入进位与范围错误；不同编码下的传统事件、现代事件与头部事件共存；参数独立文件从第1或后续块开始；空通道、截断、错误偏移、维度和限额。原有 `scripts/interop.py` 继续独立验证裁剪、统计、CSV及异常退出。

0.2.1新增小数采样率的舍入区间、时间与索引往返、精确半开裁剪、自定义限额与UTF-8预算回归。59.94 Hz / 3子采样的三种编码输出另按独立Python字节解码器核对；`py-c3d 0.6.0` 的部分小数率/编码组合仍会因其精确比率断言而拒绝，不能单独作为此类输入的正确性判据。原有官方及合成数据的独立对照继续保留。

上述独立验证现已保存为 `scripts/review_regressions.py`，在JS CLI构建后运行，输出唯一 `artifacts/review-regressions-*/report.json`：59.94/29.97/23.976 Hz × 3/10子采样 × 三编码 × 整数/浮点共36例，100 Hz两组半开时间裁剪 × 三编码 × 两种存储共12例。全部物理样本以独立字节解码器核对，48例与前述21个兼容案例、54个转换输出分开统计。

跨模块公开API使用方式可运行 `python scripts/verify_consumer.py` 验证；它从仓库模板生成独立MoonBit模块及`moon.work`，检查并运行三编码、59.94 Hz、3子采样和时间裁剪流程，报告位于 `artifacts/source-consumer-*/result.json`。这两项验证均进入CI，详细终验复现入口见 [FINAL_REVIEW.md](FINAL_REVIEW.md)。

## 文本系列与资源边界

读取文本系列按连续编号拼接，可识别历史127项分段和末尾预留容量；未提供的标签用索引生成，描述/单位补空串。缺少中间编号而存在更高编号会报错。数值校准系列必须完整，不能用默认值掩盖半套校准；全系列缺省时采用格式默认值。写出统一按255项分段，保留合法维度。

计数的格式上限各65535，不表示任意65535通道文件都能写出。每帧模拟样本数必须≤65535，参数区最多255块，文本宽度/单维度≤255，并受默认128MiB文件、20,000,000总数值等预算限制。超过资源预算返回 `resource_limit`，调用者可调整 `Limits` 中非格式本身的限额。

内部事件时间轴是原试次的绝对秒数。头部事件按文件首样本相对秒数读取后加TRIAL起点；EVENT参数沿用内部绝对时间约定。精确相同时间与标签的头部副本不重复加入，保留现代事件上下文；显示标志不作为删除事件依据。写出迁移到 EVENT 参数，最多255个事件；厂商自定义时间约定需调用者明确适配。

FORCE_PLATFORM 等参数按类型保留和转码，不实现力/力矩推导、运动学模型或骨架重建。存在有效力平台引用时模拟通道选择会拒绝，以免误改引用；未知厂商通道引用不自动重映射。这些属于应用算法及私有语义边界，不再以不支持某种标准处理器编码作为终点。
