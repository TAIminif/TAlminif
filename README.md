# TAlminif — MoonC3D

MoonBit-native C3D motion-capture file exchange and synchronized editing.

Development targets Intel IEEE little-endian C3D, point and analog samples,
parameter preservation, validation, cropping, channel selection and a file CLI.
The implementation is in progress; supported features and executable examples
will be documented as they become available.

The module and repository are both `TAIminif/TAlminif`. MIT licensed.

Current development check: `moon test`.
